# HalaPOS Docs

Documentation for **HalaPOS** — a desktop & cloud point of sale solution you can set up in under thirty minutes.

Download the [HalaPOS - Desktop & Cloud Point of Sale App](https://www.halapos.com/download). If you haven't purchased a license yet, you can register an account to download the free version.

## Local development

This is a [Next.js](https://nextjs.org) site that uses [Markdoc](https://markdoc.dev) for content and [Tailwind CSS](https://tailwindcss.com) for styling.

```bash
pnpm install   # install dependencies
pnpm dev       # start the dev server at http://localhost:3000
pnpm build     # build the static site into docs/ (served by GitHub Pages)
```

Documentation pages live in `src/pages` as Markdown. The left-hand navigation is defined in `src/pages/_app.jsx`.
