## Application Alerts

![Alerts](/images/light/alerts.png 'Alerts')
![Alerts](/images/dark/alerts.png 'Alerts')

Application alerts show low-stock items, customers reaching their due limit, and pending sales and purchases.

---

## Tax & Total Report

![Reports](/images/light/reports.png 'Reports')
![Reports](/images/dark/reports.png 'Reports')

This report displays the tax and total amount for sales, purchases, expenses, payments, return sales, return purchases, damaged stock, expired stock, and found unknown stock.

---

## Sales Reports

This report displays the list of sales, with options to filter by reference, status, customer, user, start date, and end date.

---

## Purchases Reports

This report displays the list of purchases, with options to filter by reference, status, supplier, user, start date, and end date.

---

## Expenses Reports

This report displays the list of expenses, with options to filter by reference, user, company, tax number, start date, and end date.

---

## Payment Reports

This report displays the list of payments, with options to filter by reference, customer, supplier, user, payment method, start date, and end date.

---

## House Keepings Reports

This report displays the list of house keepings, with options to filter by reference, type, customer, supplier, user, start date, and end date.
