---

## Add/Edit

The add/edit tax page uses the same form, with the following fields:

1. **Name**: tax name
2. **Code**: (optional) the tax's code number, if any
3. **Rate**: tax rate
4. **Type**: fixed/percentage
5. **State Level**: (optional) whether the tax is state-level
6. **Same State**: (optional) apply the tax only when the business and customer/supplier are in the same state
